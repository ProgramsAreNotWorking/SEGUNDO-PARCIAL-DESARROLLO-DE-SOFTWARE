# Requerimientos del software

- El software debe permitir al usuario registrar estudiantes.

- El software debe permitir agregar calificaciones a los estudiantes.

- El software debe permitir al usuario ver promedio de estudiantes.

- El software debe permitir al usuario ver estadisticas generales de los estudantes.

- El usuario debe poder cerrar el software.

- El software debe permitir registrar varias calificaciones a un solo estudiante.

- El software debe mostrar promedio general del curso.

- El software debe poder mostrar al estudiante con mayor calificacion en un curso.

- El software debe poder mostrar al estudiante con menor calificacion en un curso.

- El software debe poder mostrar la cantidad de estudantes aprobados.

- El software debe poder mostart la cantidad de estudantes reprobados.
